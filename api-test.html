📚 API Documentation

Reference Guide

🔗 Base URLs

  • Development: http://localhost:3001
  • Production: https://api.hamedaei.com
  • Direct IP: Use /api/ prefix

🔐 Authentication

  • Type: Bearer Token (JWT)
  • Header: Authorization: Bearer {token}
  • Login: POST /api/admin/login
  • Token Duration: 24 hours

📊 Response Format

{
  "message": "string",
  "data": "any",
  "error": "string (optional)",
  "meta": {
    "page": "number",
    "limit": "number", 
    "total": "number"
  }
}

📁 File Upload

  • Max Size: 10MB per file
  • Types: JPEG, PNG, GIF, WebP
  • Field Names: image, mainImage, additionalImages
  • Multiple Files: Supported for works

🚀 Quick Start Guide

  1. Authentication: Click "Create Admin" to set up an admin account, then "Login"
  2. Test Public APIs: Use the green "Test All Public APIs" button to verify public endpoints
  3. Test Admin APIs: After login, use "Test All Admin APIs" to verify authenticated endpoints
  4. CRUD Operations: Use the "Test All CRUD Operations" for comprehensive testing
  5. Create Content: Use the "Create" buttons to add categories, works, texts, and images
  6. Advanced Testing: Use the advanced tools for pagination, performance, and error testing

🔄 HTTP Status Codes

✅ Success Codes
  • 200 OK - Request successful
  • 201 Created - Resource created
❌ Error Codes
  • 400 Bad Request - Invalid input
  • 401 Unauthorized - Auth required
  • 404 Not Found - Resource missing
  • 500 Server Error - Internal error

💡 Testing Tips

  • Start with Health Check: Test /health endpoint first
  • Create Before Update: Create resources before testing update/delete operations
  • Check Response Times: Use performance testing for optimization insights
  • Test Error Scenarios: Verify proper error handling with invalid inputs
  • Export Results: Save test results for documentation or debugging
  • Pagination Testing: Test with different page sizes and limits
